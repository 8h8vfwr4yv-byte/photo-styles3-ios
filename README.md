# 18 Pro 影像（PhotoStyles3）

一个 iOS 照片风格化 App：把普通照片处理成"像 iPhone 18 Pro 的新影像系统拍出来的"画面。

流程：从相册选照片 → 选一种新影像风格 → 调强度、开关叠层 → 保存到相册。

四种风格（都是整幅画面的相机系统质感，不是相框、不只是文字边框）：
- **标准影像**：均衡的出厂质感
- **冷色科技**：冷调 + 高动态范围 + 镀膜辉光
- **镀膜幻彩**：镜头镀膜的彩色反光为主角
- **胶片纪实**：胶片曲线 + 明显颗粒

处理管线（Core Image）：高级动态范围（压高光提暗部）→ 冷色调色 → 镀膜反光（两团彩色辉光 + 斜向耀光，滤色叠加）→ 轻微锐化 → 胶片颗粒；最后用 Core Graphics 把**半透明设备信息叠层**（顶部设备芯片、四角取景线、底部拍摄参数行）和**极简水印**直接合成进画面，保存为成品图。日期取自照片自身的 EXIF。

## 构建

GitHub Actions 使用 Xcode 27.2 / iOS 27.2 SDK（`xcode-27` runner）构建未签名 IPA，最低系统 iOS 17.0。

## 安装

用 AltStore / SideStore 安装 `PhotoStyles3.ipa`（会用你的 Apple ID 重新签名）。
